# ChipMate v0.4.2

堵住 v0.4.1 鉴权里的一条绕过路径，并补上后端 CI。

## 修复

- **`/token` 的无 Origin 绕过**：旧逻辑是「有 Origin 且不在白名单才拒绝」，用 `<img>`、`<form>`、`no-cors` 之类不带 Origin 的请求可以直接把令牌读走。现在改为「Origin 必须在白名单内才下发」，没有 Origin 一律 403
  - 影响面：本机开发模式（5173/5174）不受影响；打包版本来就走 preload 注入令牌，不依赖该接口
  - 独立用 curl 调试后端的话，令牌请直接读 `<data>\token.txt`

## 新增

- **后端 CI**：`.github/workflows/backend-tests.yml`，Windows runner 上装依赖跑 19 个 unittest
- 单测补一条 `no origin -> 403`

## 验证

- 后端 19 个单测全过
- 打包版实测：渲染进程注入 32 位令牌，无令牌 POST 401、带令牌 POST 200，界面串口日志正常滚动；同一个页面请求 `/token` 返回 403
- 安装包资产下载后 SHA256 与本地一致

## 说明

- 安装包仍未代码签名；首次运行时若被杀软拦下，把文件挪到别处（例如下载目录）再执行即可
- 静默升级时旧版必须先退出
