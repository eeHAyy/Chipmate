# ChipMate v0.3.1

v0.3.0 上线后自查发现的三处首次使用问题，一并修掉。

## 修复

- **设置页切预设存不住**：旧逻辑只在「接口地址/模型」不等于默认值时才提交，导致从豆包切回 DeepSeek 之类会静默不保存。现在每次保存都完整提交接口地址与模型
- **设置页标题重复**：标题曾渲染成「AI AI 设置」，改为「AI 设置」
- **说明文字多出冒号**：预设说明末尾会跟一个孤立「：」，已去掉
- **保存/清除反馈误判**：失败提示曾按「是否含『失败』两个字」上色，英文提示会显示成绿色成功样式，改为显式成功/失败状态

## 新增

- **无 Key 时点发送直接去设置**：以前会先发出去再报错，现在直接打开 AI 设置面板，输入内容不丢
- **欢迎页示例问题**：三个可点击的常见问题（串口配置、烧录打不开 COM 口、UsageFault 日志），点一下填进输入框，降低空白页门槛
- **豆包预设补说明**：模型名要填火山方舟的接入点 ID（`ep-` 开头），不是 `doubao-pro-32k`
- README 截图更新为 0.3.1 实际界面

## 说明

- 安装包仍未代码签名，首次运行会有 SmartScreen 提示
- 静默升级（`/S`）时若旧版正在运行会安装失败，请先退出 ChipMate 再安装
