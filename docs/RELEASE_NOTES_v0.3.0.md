# ChipMate v0.3.0

按 v0.2.1 的可用性评估做的第一轮体验改造。

## 新增

- **未配置 Key 的顶部提示**：聊天区顶部会出现「未配置 API Key，AI 对话不可用 · 去设置」，点一下直接打开设置面板，配置完自动消失
- **手册缺失说明**：选中尚未导入手册的芯片时，左侧会说明「AI 会基于通用知识回答，拖入 PDF 后可引用具体引脚与寄存器」，不再让人对着 `No data` 猜
- **应用图标**：替换默认 Electron 图标，安装包、exe、快捷方式统一使用 ChipMate 图标

## 变更

- **数据目录迁移到用户目录**：运行时数据（芯片手册、设置、固件）从安装目录 `_internal\data` 迁到 `%APPDATA%\ChipMate\data`，卸载、覆盖升级不再丢配置；首次启动会自动把老版本残留的数据搬过来
- **冷启动体验**：窗口先出现，后端就绪后前端自动重连（健康检查改为失败后每 1.2 秒重试），不再干等 3–5 秒白屏

## 说明

- 安装包仍未代码签名，首次运行会有 SmartScreen 提示
- 内置芯片列表只有型号，没有手册数据；要引用具体引脚/寄存器仍需自行导入 PDF
